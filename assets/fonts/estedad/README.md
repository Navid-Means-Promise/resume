# Estedad

Primary Persian résumé titles use Estedad 8.5 by Amin Abedi.

- Upstream: https://github.com/aminabedi68/Estedad
- Upstream release: `8.5` (`97d10596b3a260c040336199c2e83a6305d37663`)
- Webfont distribution: Fontsource `estedad:vf@5.3.0`
- License: SIL Open Font License 1.1; see `OFL.txt`

The Arabic and Latin variable WOFF2 subsets are stored separately so mixed
Persian/English technical headings remain compact while the résumé works fully
offline.
