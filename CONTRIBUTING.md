# Contributing

Create a dedicated `feat/`, `fix/`, `docs/`, `test/`, `refactor/`, or `chore/` branch before editing. Keep each branch to one coherent change and run `npm run check` before requesting review. Only the repository owner merges into `main`.

Commit subjects use `TYPE: <imperative summary>`, with an optional short body explaining why. Do not add tooling signatures or generated-output commits.
